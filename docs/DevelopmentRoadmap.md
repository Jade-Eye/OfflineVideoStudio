# Development Roadmap

**Author : Mohit Singh**

Development is phase-gated. Calendar estimates are planning targets; acceptance criteria determine completion.

1. Architecture/project definition
2. Application foundation
3. Project manager/filesystem
4. Database/domain model
5. Knowledge Studio
6. Story/plot engine
7. Character Studio
8. Image production
9. Audio Studio
10. Sequencer/preview
11. Video generation/rendering
12. Training Studio
13. Model registry/evaluation
14. Controlled continuous learning
15. Multimodal orchestration
16. Continuity/validation
17. Optimization/reliability
18. UI polish
19. Full-system testing
20. Windows packaging/release

New ideas are discussed first and classified as current phase, architectural correction, future feature, experiment or rejected.
