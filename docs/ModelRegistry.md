# Model Registry

**Author : Mohit Singh**

Tracks local models, versions, adapters, capabilities, runtime requirements and evaluation results.

States: Experimental, Evaluating, Approved, Stable, Deprecated, Rejected.

Production projects record the exact model versions used for approved content. A newly trained model never silently replaces a production model.

Generation records should eventually capture model version, adapter, prompt/template version, seed where supported, settings and reference asset IDs.
