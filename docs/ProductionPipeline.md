# Production Pipeline

**Author : Mohit Singh**

The system is image-first:

```text
Project -> Story -> Plot -> Production Blueprint -> Scene Plan -> Shot Plan -> Scene Images -> Review -> Audio -> Sequencer -> Preview -> Continuity Validation -> Video/Assembly -> Final 1080p Render
```

Project types include single video, short film, movie, series and episodes. The user specifies target duration; the system estimates production segments and the user can edit them.

Maximum output resolution: 1920x1080.
