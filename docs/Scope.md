# Project Scope

**Author : Mohit Singh**

Core scope: fully offline single-user Windows desktop app; Python 3.11.15; modern/exotic UI; anime and realistic production; user photo or AI avatar characters; story/plot/chapter/scene/shot management; duration-based planning; image-first production; multilingual architecture; TTS/STT/audio; sequencer and preview; final 1080p rendering; PostgreSQL + pgvector; Knowledge Studio; Training Studio; model registry; continuity validation; CPU/GPU-aware execution; Windows installer.

Language strategy: English and Hindi first, then major Indian regional languages, Asian languages and other languages supported by verified local models. A language shown in the UI is not considered supported until the required local capability is verified.
