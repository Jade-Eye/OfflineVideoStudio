# Offline AI Video Production Studio

A planned Windows desktop application for private, offline AI-assisted video production. The project documentation describes an image-first workflow with story, character, scene, audio, sequencing, local model, and rendering components.

## Current status

This repository is in **Phase 0**. The status document marks project structure, environment verification, and baseline architecture accepted; documentation remains in progress and final Phase 0 acceptance is pending. The source tree is a starter structure, not a completed production application.

The capabilities above describe intended scope, not features currently implemented or runnable.
